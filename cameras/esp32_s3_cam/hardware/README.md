# esp32_s3_cam hardware

No board-specific design work yet — the Waveshare ESP32-S3-CAM is used on its stock
board. This directory is the slot for it when there is: enclosure CAD,
a carrier PCB, and any optics/power sizing specific to this camera.

See [`../../pi5cam/hardware/`](../../pi5cam/hardware/) for the conventions
(design source in git, exports regenerated under `export/`).
